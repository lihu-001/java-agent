# 代码审查

按以下步骤执行，不要跳步：

1. 用 glob 找出用户指定范围内的文件；范围不明确时只审查工作目录根下的文件，并在结论中说明。
2. 逐个用 read_file 读取，不修改任何文件。
3. 按“严重 / 一般 / 建议”三级列出问题，每条写明文件路径、位置（行号或片段）、问题和修改建议。
4. 没有发现问题的文件也要列出，写“未发现问题”。
5. 最后一行给出总体结论：可以合并 / 修改后合并 / 需要重写。

不要声称运行过测试或编译，除非确实用 shell 执行过并看到了结果。
