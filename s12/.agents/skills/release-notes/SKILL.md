# 发布说明

1. 优先使用用户在对话中给出的改动；没有时用 read_file 读取工作目录下的 CHANGES.txt，不存在就直接询问用户，不要编造。
2. 按以下固定结构输出，没有内容的小节写“无”：

```text
## 版本 <版本号，未知时写“未定”>

### 新增
### 修复
### 不兼容变更
### 升级提示
```

3. 每条一句话，面向使用者描述效果，不写内部实现细节。
4. 只有用户明确要求保存时，才用 write_file 写入 RELEASE_NOTES.md，写入前说明路径。
